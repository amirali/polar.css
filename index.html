Readable defaults

Bring clean typography, spacing, and semantic layout to raw HTML without utility classes.

Typography

This theme keeps contrast soft but readable, using Nord-inspired surfaces and accents. Links, lists, inline code, and block content all work out of the box.

“Design should stay out of the way until it has something useful to say.”

Inline with grid

Use data-layout="grid" or class="inline-grid" when cards, fields, or other blocks should sit side by side.

Inline with flex

Use data-layout="flex" or class="inline-flex" when items should wrap fluidly in a row.

Forms

This demo follows your system theme automatically. Set data-theme="light" or data-theme="dark" on the root element to force a specific mode.

Notes

Why classless?

It is ideal for prototypes, docs, personal sites, and MVPs where raw HTML should already feel designed.

Tip: add data-theme="light" or data-theme="dark" to the root element if you want to pin the theme instead of following prefers-color-scheme.

Made for simple pages that want a cold, calm Nordic vibe.
